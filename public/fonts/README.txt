Self-hosted, subset fonts (Latin + Vietnamese, no hinting), built from Google Fonts sources (github.com/google/fonts):
- Noto Serif Display: static instances wght 300/400 (wdth 100), 650 (wdth 75), italic 400. SIL OFL 1.1, see OFL-NotoSerifDisplay.txt
- Be Vietnam Pro: Regular, Medium, SemiBold, Italic. SIL OFL 1.1, see OFL-BeVietnamPro.txt
Rebuild: scripts/build-fonts.sh

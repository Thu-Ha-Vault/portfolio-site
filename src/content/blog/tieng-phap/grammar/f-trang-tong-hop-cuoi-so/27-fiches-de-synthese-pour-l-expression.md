<!-- Ảnh 3544 (trang viết xoay ngang, nằm cạnh sơ đồ French Moods) -->
- **Pour + durée** (tổng temps (?)): prévu + k⁰ (không) l.quan (liên quan) đến thì.
- \* **Il y a ... que** = **Depuis** ≠ **Il y a** (→ [Prépositions](/blog/tieng-phap/grammar/d-phu-dinh-cau-hoi-gioi-tu-dai-tu-lien-tu/12-les-prepositions/))
- **entre + début + et + fin**: commencer et finir n'importe quand entre cette durée.
- **À partir de** + nom / année ✗ **jusqu'à** → thì nào cũng được.
- **Les indicateurs de temps**: (→ Indicateur de temps trong [Expressions pour l'expression écrite](/blog/tieng-phap/writing/01-expressions-pour-l-expression-ecrite/))
	- "**en + moment**" pour un moment dans le passé + PS.
	- "**Il y a + temps passé**" pour un moment dans le passé + PS. (→ [Il y a: ago](/blog/tieng-phap/grammar/b-danh-tu-tu-han-dinh-trang-tu-tinh-tu/05-les-adverbes/))
	- "**Depuis + moment (quand) / durée**" pour une activité qui a commencé dans le passé et qui dure jusqu'à aujourd'hui + présent (→ [Présent](/blog/tieng-phap/grammar/e-thi-thuc-the/17-present-passe-recent-et-passe-compose/))
		- ↳ có thể đi với PS (hiếm): ĐT kết thúc tại thời điểm nói.
	- "**De + moment + à + moment**" pour une durée + PS.
	- "**Pendant + nom / durée**" + PS. → thì nào cũng được → hđ (hoạt động) xảy ra liên tục
	- "**En + durée**" pour la réalisation d'une action + PS. (nécessaire → accomplir) → thành tích
		- (mois, année, saison – printemps)
- **La cause**: à cause de ✗ grâce à. (→ Cause trong [Expressions pour l'expression écrite](/blog/tieng-phap/writing/01-expressions-pour-l-expression-ecrite/); [Les conjonctions](/blog/tieng-phap/grammar/d-phu-dinh-cau-hoi-gioi-tu-dai-tu-lien-tu/15-les-conjonctions/))
	- parce que: ne savais pas la raison → pourquoi
	- **à cause de + nom**: exprimer une cause qui a un résultat négatif: conséquence négative + à cause de + cause négative.
	- **Grâce à + nom/pronom**: exprimer une cause qui a un résultat positif. Grâce à + cause positive, conséquence.
	- **Comme + phrase**: si la cause est dans la première partie.
		- → nhấn mạnh nguyên nhân
		- → positif / négatif
	- **car**, **puisque**: savais la raison → ✗ pourquoi

- **La conséquence**: donc, alors, c'est pourquoi, du coup, c'est pour ça que (→ Conséquence trong [Expressions pour l'expression écrite](/blog/tieng-phap/writing/01-expressions-pour-l-expression-ecrite/))
- **L'opposition**: mais, pourtant, cependant, par contre (trái lại), en revanche, alors que (?), néanmoins (tuy nhiên) (→ Contradictoire, Concession / opposition trong [Expressions pour l'expression écrite](/blog/tieng-phap/writing/01-expressions-pour-l-expression-ecrite/))
- **sans + nom** sans articles
- **ne ... que**: seulement (→ [Négation](/blog/tieng-phap/grammar/d-phu-dinh-cau-hoi-gioi-tu-dai-tu-lien-tu/10-la-negation/))
- **Les quantités précises** + nom sans articles. (→ [Déterminants](/blog/tieng-phap/grammar/b-danh-tu-tu-han-dinh-trang-tu-tinh-tu/04-les-determinants/))
- *(Khung bên phải trong sổ:)*
	- **Le but**: pour, afin de + V (?) (→ pour que, afin que + subjonctif trong [Subjonctif](/blog/tieng-phap/grammar/e-thi-thuc-the/22-le-subjonctif/))
	- **La concession**: C'est vrai que, ce n'est pas faux que (→ Concession / opposition trong [Expressions pour l'expression écrite](/blog/tieng-phap/writing/01-expressions-pour-l-expression-ecrite/))
	- **La réfutation**: *(để trống)*
- **Les adjectifs indéfinis**: (→ [Déterminants – tout, indefinite](/blog/tieng-phap/grammar/b-danh-tu-tu-han-dinh-trang-tu-tinh-tu/04-les-determinants/))
	- une petite quantité: quelques.
	- une quantité importante: plusieurs.
	- la totalité: tous les, chaque
		- Tout s'accorde avec le nom.
		- Chaque est toujours au singulier.
- **Le gérondif**: (→ [Present participle](/blog/tieng-phap/grammar/c-dong-tu/09-verbes-pronominaux-modaux-impersonnels-et-infinitif/), [French Moods](/blog/tieng-phap/grammar/f-trang-tong-hop-cuoi-so/26-les-modes-et-la-ligne-du-temps/))
	- **Formation**: en + base de la 1re pers. du pluriel au présent + -ant → participe présent
	- **Utiliser**:
		- pour proposer des solutions. (ví dụ *en construisant* trong [Test 2](/blog/tieng-phap/writing/05-test-2-proposer-un-projet-pour-ameliorer-la-vie-a-hanoi/))
		- la manière (comment?): nguyên nhân (?)
		- simultanéité: đồng thời (en même temps)
	- \* être → en étant, avoir → en ayant, savoir → en sachant
- **Participe**: rút gọn mệnh đề quan hệ "qui"; la cause (→ [Pronoms relatifs](/blog/tieng-phap/grammar/d-phu-dinh-cau-hoi-gioi-tu-dai-tu-lien-tu/14-pronoms-indefinis-demonstratifs-possessifs-et-relatifs/))
- \* de + des = de.
- \* **Le superlatif**: (→ [Adjectifs](/blog/tieng-phap/grammar/b-danh-tu-tu-han-dinh-trang-tu-tinh-tu/06-les-adjectifs/), [Adverbes](/blog/tieng-phap/grammar/b-danh-tu-tu-han-dinh-trang-tu-tinh-tu/05-les-adverbes/))
	- le / la / les + plus / moins + Adj.
	- V + le plus / moins (de...)
	- le plus + de + nom / Adv (de...)
- **Alors que + indicatif** (phrase complexe)
	- trong khi đó.
	- opposition
- **Les verbes pour exprimer la cause**: (→ Cause trong [Expressions pour l'expression écrite](/blog/tieng-phap/writing/01-expressions-pour-l-expression-ecrite/))
	- causer / être causé par (→ [Voix passive](/blog/tieng-phap/grammar/e-thi-thuc-the/25-la-voix-passive/))
	- provoquer / être provoqué par
	- être dû à
- **Un PLAN**: (→ Bố cục bài nghị luận trong [Expressions pour l'expression écrite](/blog/tieng-phap/writing/01-expressions-pour-l-expression-ecrite/))
	- **Analytique**: Situation → Causes → Conséquences → Solution.
	- **Je suis d'accord**: parce que... → solution
	- **Thématique**: conséq. écologique, économique... d'un problème
	- **Dialectique** (par l'opposition): (ví dụ: [Pour ou contre l'interdiction des motos](/blog/tieng-phap/writing/03-pour-ou-contre-l-interdiction-des-motos-et-des-voitures-a-hanoi/))
		- les avantages ≠ les inconvénients } qualité de l'argument
		- proposition.
- **Pronom**: (→ [Pronoms personnels](/blog/tieng-phap/grammar/d-phu-dinh-cau-hoi-gioi-tu-dai-tu-lien-tu/13-les-pronoms-personnels-y-et-en/))
	- V + qqch (COD) — COD: me, te, le/la, nous, vous, les
	- V + de qqch (COI → en) + à qqn (COI) — COI: me, te, lui, ..., leur
	- Elle s'est lavée. (s' = COD → herself, nên QKPT hợp giống) (→ [Accord du participe passé](/blog/tieng-phap/grammar/e-thi-thuc-the/17-present-passe-recent-et-passe-compose/))
	- Elle s'est lavé les mains (d'elle). (s' = COI, les mains = COD)
